Architecture Breakdown

AI Network Shield

A highly scalable, multi-modal forensic architecture designed to detect deepfakes, synthetic voices, and pump-and-dump schemes across the financial web.

Explore The Architecture

Core Components

Universal Control Platform

Next.js • TailwindCSS

The centralized command center for analysts. Features real-time threat intelligence dashboards, forensic evidence viewers, and node-based visualization of decentralized scam networks using force-directed graphs.

Agentic Mobile Overlay

Kotlin • React Native Edge

A frictionless background service for Android. Uses `SYSTEM_ALERT_WINDOW` to draw a floating AI agent over social media apps. With a single tap, it captures screen telemetry and triggers deep analysis without the user ever leaving Instagram or Telegram.

Distributed Scalable Crawlers

AWS EKS • Celery • S3

Containerized extraction workers deployed on Kubernetes. They asynchronously scrape raw video payloads from YouTube, Telegram (via Telethon), and Instagram, instantly piping massive media blobs directly into AWS S3 storage arrays.

Multi-Modal AI Engine

LLaVA • Mistral-7B • PyAnnote

The brain of the operation. Running on GPU-tainted EKS nodes with BitsAndBytes 4-bit quantization, this pipeline analyzes visual deepfakes via LLaVA, extracts overlapping audio with Whisper, and diarizes speakers.

Finally, a Hybrid RAG setup using LangChain and Cross-Encoders feeds historical forensic data into Mistral-7B to output a strictly JSON-formatted threat verdict.
